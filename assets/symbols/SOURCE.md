# Bundled medical-device symbol graphics — source & attribution

The 29 SVG symbol graphics in this folder are bundled (for offline use) from the
open-source, MIT-licensed repository **[t4dhg/medical-device-symbols](https://github.com/t4dhg/medical-device-symbols)**
— the manufacturer-facing symbol set for the ISO 15223-1 / ISO 7000 / IEC 60417
medical-device symbols. Treated as the source of truth for the symbol graphics.

- **License:** MIT (see the source repository).
- These are **reference representations** for a browsable glossary. The
  authoritative symbol, its exact standardized title, and conditions of use are
  defined in **ISO 15223-1:2021** — always use the standard for compliance.
